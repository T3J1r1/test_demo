# Python + GitHub Desktop Student Demo

This repository is a simple starter for students learning:

1. Basic Python ideas
2. How to use GitHub Desktop (GUI)

## What students should do

1. Clone this repository with **GitHub Desktop**
2. Create or edit a Python file (for example, `hello.py`)
3. Run the file locally (`python hello.py`)
4. Commit changes in GitHub Desktop with a clear message
5. Push the commit to GitHub

## First Python example

```python
print("Hello, class!")
```

Try changing the message, run it again, and commit your update.
